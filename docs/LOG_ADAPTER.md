# 日志适配与数据边界

解析器版本：5（采集器 0.1.4）。已核验九个精确官方版本：`0.153.0-alpha.5`、`0.153.4`、`0.154.0-alpha.6.2`、`0.155.0-alpha.9.2`、`0.155.0-alpha.16.3`、`0.158.0-alpha.2.1`、`0.160.1`、`0.162.0-alpha.2`、`0.162.0-alpha.17.2`。官方 tag、提交、字段及实现摘要见 `log-version-evidence.json`。`synthetic-v1` 仅用于夹具。未核验版本不按前缀放行。

优先消费 `token_usage_record`：按 `thread_id` 确认响应所有者，用 `response_id` 稳定去重，直接使用单次响应的 `usage`。对应源码为官方 [TokenUsageRecord](https://github.com/openai/codex/blob/740e5af33c71225640e0c1c1555c514c2c93ab74/codex-rs/protocol/src/protocol.rs#L2253) 与 [SessionState::record_token_usage](https://github.com/openai/codex/blob/740e5af33c71225640e0c1c1555c514c2c93ab74/codex-rs/core/src/state/session.rs#L218)。九个版本的线程本地累计实现摘要一致。不再将同一响应的 `token_count` 上下文通知叠加收费；该通知可能是估计或重算。

文件第一条有效 `session_meta` 确定物理日志所有者。分支文件随后复制的父头不会覆盖它；复制到分支中的父响应仍归原 `thread_id`，不重复记为子代理。非分支文件出现冲突身份会保留异常。模型使用匹配 turn ID 的上下文；没有对应上下文时保留 unknown，不猜其他 turn 的模型。

混合旧格式前缀只在可确认的累计差值下接续，缺失前缀会显示待核验。相同响应 ID 的矛盾用量保留 Token、拒绝估价并显示部分记录。只有逐响应数据自身的请求身份和数值有效，才认为请求边界已知。

输入包含缓存读取，输出包含推理。显式零缓存写入不涉及包含关系歧义；非零缓存写入在真实版本中尚无完整证据，必须返回未知价格。缺失字段保留 null，不默认零。测试契约中的 `synthetic-v1` 显式定义缓存写入包含在输入中，用于验证互斥公式。仅保存消息媒体类型标记，不保存媒体 URL 或内容。显式 input_image 在精确模型价格表声明已核验策略后，可使用已包含图片的输入及缓存 Token 计价；其他模态仍未知。

保存 `session_meta`、`turn_context`、`token_usage_record` 与回退用的 `token_count` 数字投影。新版 `response_item` 和旧 `response_msg` 的非文本类型都仅保存模态标记。图片输入标为 image-input；音频、图片输出或不明 image 标为 unsupported，后来的图片输入不能覆盖此状态。只有显式 compaction replacement_history 才能重新确认剩余模态。图片输入按已换算的日志 Token 计价一次，不保存图片地址、正文或压缩摘要。规则见 IMAGE_PRICING.md。

累计快照产生差值，重复快照不计入。差值与 `last_token_usage` 的各字段一致才认定是一个请求；无法还原请求边界时保留聚合 Token、价格 null。稳定 response/request ID 优先；没有时以会话 + 用量投影指纹去重并标记 `source-sequence`。指纹包含事件时间、请求身份、模型与累计快照，不按相同 Token 数去重不同请求。

复制、归档与多 home 用会话身份及投影指纹合并。fork 已复制的祖先证据不重复计数；无复制时用 fork 时刻之前的父累计基线。祖先缺失时第一条继承快照隔离为基线，后续差值保留；以后找到祖先会重新推导后代。未知初始累计只保留已识别最后请求，前面的继承 / 缺失部分明确待核验。祖先存在环时诊断。

累计下降没有明确序列重置证据时，不使用 `max(0, delta)` 掩盖：该事件待核验，后续建立新基线。只有显式重置或可验证的序列身份变更可产生新段。会话错误在后续扫描中保持可见，重建或修复证据后再清除。

工作子代理通过父链识别桌面来源。已核验版本的原生逐响应记录只记录当前线程完成的响应；因此可按父、子各自的响应 ID 分开相加，不重复加父累计值或分支继承基线。未知版本的计数关系仍保留待核验。显式 `usage_includes_subagents=true` 仍排除子代理。guardian / codex-auto-review 默认单列，价格未知。

会话全历史审计仍留在缓存，但逐事件异常按 UTC 时间归属到所选自然日；历史会话的版本或回退问题不再永久污染今天。没有用量的元数据不会单独造成部分记录。无法定位日期的真实文件读取 / 枚举失败仍保守告警，不静默忽略。解析器升级自动重建本工具的派生缓存，不改 Codex 原文件。

SQLite 缓存包含文件路径与偏移、文件身份与边界摘要、解析器版本、必要会话 / 父 / fork 身份、UTC 事件时间、请求 Token、模型证据、异常原因及价格版本。原始会话路径只保存在本机缓存，不返回 API。提示词、回答、工具正文、rate limit 详情、账号、认证文件与 Cookie 不进入缓存。

扫描事务同时提交行投影与偏移。半行留待下次写入，坏完整行记录诊断并继续。截断、替换、同长度改写重建文件证据。追加读取前检查已消费前缀头尾摘要；若同时追加且在已消费前缀中间修改、又不改变边界摘要，无法完全检测，维护者应执行离线 `rebuild`。没有每次哈希全历史文件，以保持增量开销。

目录变化使用 Windows ChangeNotification；失败时降级周期核对。每轮解析有时间 / 字节预算，汇总不等待全量扫描。非常长的单行最多额外读取 32 MiB，不能完成时保持部分记录诊断；不把未知丢失记录量化为零。文件读取权限、长路径支持与被占用日志仍依赖实际 Windows 文件共享策略，失败不损坏缓存或原文件。
