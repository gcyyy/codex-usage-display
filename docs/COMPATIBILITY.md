# 兼容性边界

仅面向 Windows x64。当前桥接基于 Codex++ 1.8.0、上游提交 f6092f29d6e31c5487c86c50a20e33c02c7e297e，完整包的安装器按已核验宿主 SHA-256 判断兼容性。版本名相同但哈希未知的构建不会被覆盖。宿主升级可能移除本项目桥接，需要重新核验。

解析器 5 支持九个精确核验过的官方日志版本，列表与证据在 log-version-evidence.json；未知版本保留 Token 并提示适配待核验。支持按响应 ID 去重、分支归属、桌面来源与子代理分类；不能把全部本机 home 等同于当前账号的完整账单。

图片输入定价只对价格表中明确声明策略的精确模型启用，未知模型与其他媒体不猜测。价格快照核验日期 2026-10-15，超期会提示。统计范围与计价规则见 README.md。

UI 测试覆盖明暗主题、DPI、拖动、窄屏、缩放、清理和公开桥接夹具。真实桌面布局由实际 Codex / Codex++ 版本决定，合成页面测试不能代替宿主人工验收。安装不修改官方 Codex、CSP、路由访问边界、认证或日志。
