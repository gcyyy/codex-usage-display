# 兼容性边界

仅面向 Windows x64。当前桥接基于 Codex++ 1.10.0、上游提交 85f9117fe108719c6e4807ec60025a25042345f9，完整包的安装器按已核验宿主 SHA-256 判断兼容性。版本名相同但哈希未知的构建不会被覆盖。宿主升级可能移除本项目桥接，需要重新核验。

解析器 6 支持精确核验过的官方日志版本（含 0.163.0-alpha.10.2），列表与证据在 log-version-evidence.json；未知版本保留 Token 并提示适配待核验。支持按响应 ID 去重、分支归属、桌面来源与子代理分类；不能把全部本机 home 等同于当前账号的完整账单。

图片输入定价只对价格表中明确声明策略的精确模型启用，未知模型与其他媒体不猜测。价格快照核验日期 2026-10-15，超期会提示。统计范围与计价规则见 README.md。

UI 测试覆盖明暗主题、DPI、拖动、窄屏、缩放、清理和公开桥接夹具。真实桌面布局由实际 Codex / Codex++ 版本决定，合成页面测试不能代替宿主人工验收。安装不修改官方 Codex、CSP、路由访问边界、认证或日志。

发布程序未签名；当前不提供自动更新、开机自启、系统服务、云端补采或订阅账单查询。

## 自动检测与修复提示（0.2.4）

每次面板刷新会收到当前统计范围的日志版本状态；未知版本继续保留 Token，拒绝未经验证的估价，并显示具体版本与响应数。范围开关会同步影响版本统计。

后台最多每分钟核对宿主 EXE 与安装回执；文件元数据未变化时复用 SHA-256。文件变化只表示安装产物已变化，不据此认定新版可安全覆盖。磁盘文件匹配也不等于当前页面已连接，面板分别显示实时请求结果和文件状态。

桥接被升级覆盖时，已加载面板会显示未开放路由或连接失败的修复步骤。若升级连用户脚本都停用了，则无法在面板提示；此时双击安装目录 `Check-Compatibility.cmd`。该入口不依赖 renderer 桥接，后台不在线时仍会检查宿主文件，并明确标记日志格式尚未检测。新机/无记录时不声称已验证日志。

命令行可执行 `codex-usage-collector.exe compatibility-check`；返回 0 表示本次检查通过，非零表示待处理或未完成检查。GUI 包装脚本将摘要保存到 `.runtime/compatibility-report.json`。摘要只包含版本、状态、响应计数和固定修复说明，不含令牌、原始日志路径、提示词或回答。此检测不访问更新服务器，不自动安装、降级、修改配对或放宽版本验证。

### 面板启动（0.2.5 / bridge v2）

新增 `/usage-status/start`，只接受空对象。可执行文件和状态目录由本机安装配对记录确定，不接收页面传入的路径、命令或环境变量。启动前验证现有实例的认证健康状态；已运行时复用，认证错误时不另起进程。启动使用隐藏窗口，返回结果前检查健康状态。旧配对记录回退到 Windows 默认安装目录；自定义安装目录需用新安装器更新配对。
